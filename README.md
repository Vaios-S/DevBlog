# DevBlog

DevBlog is a mini blog platform built with React, Vite, and React Router.  
The application allows users to browse articles, explore author profiles, and navigate through a protected dashboard with nested routes.

This project was created as part of an academy assignment to practice modern React routing concepts and application structure.

---

## Features

- Browse blog articles
- Dynamic article detail pages
- Author profile pages
- Protected dashboard area
- Nested routing with layouts
- Programmatic navigation
- Route parameters with `useParams`
- Navigation state with `useNavigate`
- Lazy loaded pages using `React.lazy`
- Custom 404 page
- Reusable components structure

---

## Technologies Used

- React
- Vite
- React Router DOM
- JavaScript (ES6+)
